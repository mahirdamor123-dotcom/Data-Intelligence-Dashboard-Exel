# Data Intelligence Dashboard

Excel project workbook with 250 generated customer transaction records. The original class dataset was not attached, so replace the generated Raw Data before submitting if your instructor supplied a specific dataset.

## Files
- `Data_Intelligence_Dashboard.xlsx` — formatted multi-sheet workbook with Raw Data, Analysis, Visualizations, Dashboard, and Read Me.
- `Final_Project_Dataset.csv` — same sample records as a standalone CSV.

## Open and use
Open the `.xlsx` file in Microsoft Excel and allow calculation. The Dashboard has Region, Category, and Segment dropdowns. Raw Data is an Excel table with filters. Charts are on Visualizations. Analysis includes revenue/quantity summaries, customer and product ranking formulas, date functions, a NOW timestamp, growth what-if assumption, regression formulas, and FILTER example.

Some requested features are native Excel tools and are best added from Excel UI: create PivotTables/PivotCharts from the `Transactions` table, add slicers/timeline to those pivots, and demonstrate Scenario Manager or Goal Seek via Data > What-If Analysis. The workbook includes formula-based equivalents and instructions, but generated files cannot fully author those native pivot controls. FILTER/UNIQUE require Excel 2021 or Microsoft 365.
